# LiWeTun 0.1.0 — тестовый пакет для отдельного Windows 10 ПК

[Скачать ZIP, около 18 МБ](https://github.com/pvlrdnv/liwetun-win/actions/runs/44364045177/artifacts/14456518128).
Для скачивания Actions-артефакта может потребоваться вход в GitHub. Внутри ровно
четыре файла: установщик, публичный CER, TEST-MANIFEST.json и README_RU.txt.
Приватного ключа и профилей подключения нет. Архив хранится в Actions семь дней.

Это первая ручная приёмка Windows 10 x64 на отдельном чистом ПК без других
туннельных клиентов/Wintun. Корпоративный/рабочий ПК исключён. Не удаляйте и не
отключайте чужие клиенты или защиту ради этого теста. Windows 10/11 desktop
acceptance и стабильный публичный выпуск ещё не квалифицированы.

## Начало теста

1. Сверьте SHA256 скачанного ZIP с этим значением до установки доверия. Затем
   распакуйте архив и прочтите README_RU.txt. Windows PowerShell/Get-FileHash и
   certutil уже входят в Windows; среда разработки не нужна.
2. Только на отдельном тестовом ПК, после сверки, в PowerShell от администратора
   из папки с распакованными файлами:

   ```powershell
   certutil -addstore -f Root .\LiWeTun-Owner-Test.cer
   ```

3. Запустите LiWeTun-0.1.0-owner-test.exe, проверьте издателя, установите приложение
   и откройте его через «Пуск» без постоянного запуска от администратора.
4. Сначала проверьте интерфейс, сохранение/повторное открытие профилей, трей и
   экспорт отчёта. Для подключения нужен разрешённый ключ **TrustTunnel**;
   VLESS/Xray и Hysteria2 в этой версии не поддерживаются. Сервера/ключей в архиве
   нет. Работу интернета нельзя выводить только из статуса туннеля/счётчиков.
5. Пришлите описание шага/результата, сборку Windows из winver и проверенный ZIP
   отчёта из «Поддержки». Не присылайте ключ, данные корпоративной сети или полный
   рабочий стол.

## Завершение

Отключитесь, закройте приложение и трей, затем удалите LiWeTun через приложения
Windows **до истечения сертификата**. Только после успешного удаления приложения,
в PowerShell от администратора, удалите ровно его тестовый сертификат:

```powershell
certutil -delstore Root 3604B5653AD18DA11E0041431A04DF2E8C773381
```

При неудачном удалении приложения пока сохраните сертификат/архив и сообщите
ошибку. Не меняйте DNS, маршруты, firewall или другие сертификаты вручную.
