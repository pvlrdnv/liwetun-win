# LiWeTun

Самостоятельный клиент подключений для Windows 10/11 x64. Отдельный репозиторий,
без общей истории, runtime или зависимостей от checkout LikeWeb.

Статус: прототип клиента, **не выпущен для обычной установки**.

Реализованы импорт TrustTunnel, управление отдельной Windows-службой,
HTTPS-обновление подписок, защищённое хранение профилей и журнала, экспорт отчёта
и настраиваемое поведение трея. Серверный формат подписки остаётся предложением
клиента; изменения и интеграция LikeWeb в этом репозитории не выполняются.
Hysteria2/Xray, автоматический выбор, автозапуск и автоподключение пока недоступны.

На одноразовом Windows Server 2022 CI прошли сборки, подписанная служба/IPC,
установщик с временной CI-подписью, реальные HTTPS/DNS через TUN по HTTP/2 и HTTP/3,
проверки отказа и восстановления сети. Синтетический IPv6-стенд переводит выход
в IPv4; нативный IPv6-выход и DNS по IPv6 остаются отдельными проверками.

Отдельный SDK-кандидат предоставляет агрегированные TX/RX-наблюдения. Они
учитывают ограниченный класс потоков, включая фоновые задачи, и не доказывают
работу DNS или интернета. Недоступные и устаревшие метрики остаются неизвестными.
Приложение отличает запуск туннеля от проверенного прохождения данных.

Доверенная выпускная подпись, окончательная проверка комплекта распространения
и отдельная приёмка установленного приложения на Windows 10 и Windows 11 ещё
не завершены. Актуальные результаты и ограничения: [docs/STATUS.md](docs/STATUS.md).

## Разработка

Зафиксированная отправная точка: Flutter 3.38.10 / Dart 3.10.9.

```sh
flutter pub get
flutter analyze
flutter test
```

На Windows с Visual Studio Desktop development with C++ и Rust 1.95.0
(Cargo должен быть в PATH; версия закреплена в rust-toolchain.toml):

```powershell
flutter doctor -v
flutter run -d windows
flutter build windows --release
```

Сборка оболочки не является выпуском: подпись, SDK, служба, маршрутизация,
DNS/IPv6 и приёмка на чистой Windows остаются отдельными gates.
Для Windows реализовано защищённое хранение ссылок через пользовательский DPAPI;
нативные проверки и восстановление профилей через GUI прошли Windows CI.
При ошибке хранилища интерфейс явно сообщает о работе только в памяти.
Реализованы HTTPS-обновление подписок из интерфейса, при запуске и по расписанию.
Контракт выдачи пока является предложением клиента; интеграция с LikeWeb
и приёмка на настольных Windows остаются открытыми.

Для получения превью настоящих Flutter-экранов (без запуска нативного ядра):

```sh
flutter test tools/render_previews_test.dart --dart-define=PREVIEW_FONT=<flutter-sdk>/bin/cache/artifacts/material_fonts/Roboto-Regular.ttf
```

Изображения записываются в `build/previews/` и не коммитятся. Векторный источник
иконки: `assets/brand/liwetun.svg`; ICO воспроизводится командой
`python3 tools/generate_icon.py` без внешних пакетов.

Реальные credentials, конфигурации и production-данные сюда не переносить.
Публикация и изменение серверных репозиториев LikeWeb в текущий этап не входят.
